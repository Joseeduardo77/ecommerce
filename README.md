# 🛍 LojaTop - E-commerce

Um projeto de *E-commerce completo* desenvolvido com *React + Vite, com carrinho persistente usando **localStorage* e rotas utilizando *HashRouter* (compatível com GitHub Pages).

🔗 *Acesse o site:* [https://joseeduardo77.github.io/Ecommerce/](https://joseeduardo77.github.io/ecommerce/#/)

---

## 🚀 Funcionalidades

- ✅ Listagem de produtos com imagens
- ✅ Adição de produtos ao carrinho
- ✅ Carrinho persistente (dados salvos no localStorage)
- ✅ Remoção de produtos do carrinho
- ✅ Cálculo automático do valor total
- ✅ Layout responsivo e estilizado

---

## ⚙ Tecnologias Utilizadas

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [React Router DOM](https://reactrouter.com/)
- CSS puro
